# 六都市長候選人永續韌性城市政策承諾──一頁式倡議網站設計文件

日期：2026-08-27。設計已經 Joseph 口頭核可（對話中逐項確認）。

## 目標

為「六都市長候選人永續韌性城市政策承諾」行動（九個公民團體發起，綠盟主責）製作獨立的一頁式倡議網站。網站要完成三件事：讓選民理解六都為何是永續韌性的關鍵戰場、完整呈現五大面向 18 項政策訴求、公開追蹤六都市長候選人的簽署狀態並收公民連署。

成功標準：
- `npm run build` 通過（TS strict、無 any）
- 所有資料區塊具備載入中／讀取失敗／暫無資料三種狀態
- `prefers-reduced-motion` 開啟時動畫關閉、內容完整可讀
- 手機（375px）、平板（768px）、桌機（1280px+）三種寬度版面正確
- 試算表資料變動後，重新整理頁面即反映（不需重新部署）
- 連署表單送出後資料落入試算表、頁面顯示成功狀態並更新計數；失敗時顯示錯誤且不吞錯
- 所有中文文案經 humanizer-zh-tw 檢查

## 頁面架構（單頁滾動）

吸頂膠囊狀導覽列：錨點（六都關鍵、五大訴求、行動時程、簽署看板、連署響應、關於我們）＋右側常駐「加入連署」CTA。手機收合為漢堡選單，CTA 仍常駐。

1. **Hero**：米色底、投票箱圖示、紫漸層大標「面對城市的下一個十年，六都市長準備好了嗎？」＋副標（doc 首段文案）。綠藍城市天際線 SVG 線稿：載入時逐段描繪（stroke-dashoffset 動畫），滾動時多層視差。兩個即時數字（候選人已簽署 n 位、公民連署 n 人）＋兩顆按鈕（看簽署結果→#簽署看板、加入連署→#加入連署）。
2. **六都為什麼關鍵**（滾動敘事，GSAP ScrollTrigger pinned 場景）：三個大數字依序進場滾動計數──人口 1,650 萬（69.9%）、用電 65%、碳排 70%+──各配一句重要性說明與天際線圖像變化（人口→建築亮起；用電→窗燈閃爍；碳排→煙霧升起後被抹去）。段末補充圖表：各暖化情境（1.5／2／3／4度）下六都高溫天數增幅（資料取自「全台縣市高溫風險數據整理」試算表，只取六都列）。
3. **五大訴求**：五張卡片（一、再生能源與產業永續轉型；二、防災韌性與民生保障；三、高溫調適與健康安全；四、水患治理轉型；五、永續交通轉型），各含專屬圖示、一句話摘要；點開展開該面向引言全文＋底下 3–5 項具體訴求（全文來自附件一，共 18 項）。
4. **行動時程**：橫向時間軸五節點（8/12 記者會公布→9/11 回覆拜會意向→9/18 前拜會→9/28 簽署截止→10 月初公布結果），依今日日期高亮目前階段。手機轉直向。
5. **簽署看板**：六都分組切換（臺北、新北、桃園、臺中、臺南、高雄）。每位候選人一張卡片：姓名、政黨、狀態徽章（已簽署 n 項／部分簽署／已拜會／未回應）。點開展開 18 項勾選明細（勾選／未勾選以 SVG 圖示呈現）。未回應者一律列出。資料來自試算表「候選人簽署」工作表。
6. **公民社會連署響應**：團體連署牆（名稱＋外連，有 logo 放 logo）＋個人連署計數＋同意公開的留言跑馬燈（hover 暫停、reduced-motion 時轉為手動橫捲）。
7. **加入連署**：站內表單──身分（個人／團體）、姓名或團體名稱、Email、居住縣市（下拉）、留言（選填）、是否同意公開留言（checkbox）。送出→Apps Script→試算表。送出中按鈕 disabled、成功顯示感謝狀態並更新計數、失敗顯示錯誤與重試。
8. **關於我們**：九個發起團體（綠色公民行動聯盟、台灣氣候行動網絡研究中心、台灣環境規劃協會、主婦聯盟環境保護基金會、環境權保障基金會、地球公民基金會、還路於民行人路權促進會、台灣河溪網協會、台灣身心障礙者自立生活聯盟），各連外部網站。
9. **Footer**：聯絡（gcaa@gcaa.org.tw）、授權、綠盟捐款連結、完整天際線收尾。

## 資料架構

單一 Google Sheet 作為後台（發布到網路後由前端讀取），四個工作表：

1. `候選人簽署`：縣市｜姓名｜政黨｜狀態（已簽署／部分簽署／已拜會／未回應）｜18 個勾選欄（對應 18 項訴求）｜簽署日期｜照片URL（選填）
2. `團體連署`：團體名稱｜網站連結｜logo URL（選填）｜連署日期
3. `個人連署`：時間戳｜姓名｜Email｜縣市｜留言｜同意公開（表單寫入目的地；前端只讀計數與「同意公開」的留言、姓名遮蔽處理，Email 永不出現在前端）
4. `網站設定`：key-value（例如 phase=簽署期／公布期、公告文字）

前端讀取用 gviz JSON endpoint（`https://docs.google.com/spreadsheets/d/{id}/gviz/tq?tqx=out:json&sheet={name}`），需 Sheet 設為「知道連結的人可檢視」。個人連署的 Email 欄位隱私處理：gviz 抓整表會暴露 Email──因此個人連署改為 Apps Script 同時提供 doGet 回傳「計數＋公開留言」的過濾後 JSON，前端不直接讀該工作表。

## 表單流程

站內表單 POST 至 Google Apps Script Web App（以 GCAA 帳號部署，交付完整 script 程式碼與部署步驟文件）：
- doPost：驗證欄位→appendRow 至`個人連署`或`團體連署`→回傳 JSON
- doGet：回傳 {個人連署數, 團體連署數, 公開留言[]}（過濾未同意公開者、遮蔽姓名第二字）
- 防濫用：honeypot 欄位＋前端節流；不做 CAPTCHA（保持零依賴）

## 技術

- React 18 + TypeScript（strict）+ Vite + Tailwind CSS
- GSAP + ScrollTrigger（滾動敘事）；圖表用 Recharts 或手刻 SVG（高溫圖表單一，傾向手刻）
- 部署 GitHub Pages（`gh` CLI 建 repo），之後掛 gcaa.org.tw 子網域（管理者加 CNAME）
- 無後端伺服器；Apps Script 為唯一雲端邏輯
